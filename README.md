# 跑腿路线台
用户手填有向点对点分钟矩阵，Held–Karp子集动态规划精确计算从首地点出发的一次访问顺序。2–9地点，回起点/任意终点；缺失边不自动补齐。经典脚本，无依赖网络，不使用地图API，不含实时路况、营业时间、办事等待。并列只输出一种最短路线。

虚构默认数据：输入顺序59分钟，最短39分钟（家→菜店→图书馆→药店→取件站→家）。末站结束29分钟。结果不代表真实出行节约。

`node build.cjs` 构建单HTML；`node --test tests/core.test.cjs` 核心测试；本目录可直接静态部署。封面脚本需sharp（现有环境路径），可改为本机已安装sharp路径。

CSV完整名称；PNG结果卡长名称缩写；JSON条件可备份导入。浏览器手动保存恢复。CSV对以公式字符开头名称添加单引号防止表格执行。
